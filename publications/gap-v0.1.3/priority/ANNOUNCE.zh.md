## 标题

**把"1+2 不是 1+1"做成机器可查的定理——兼对 arXiv:2611.09007v1 的一条内核复核**

## 正文

哥德巴赫猜想仍然开放。我们做的不是证明它，而是把两件常被含糊带过的事，变成了
Lean 4 里经内核复核的定理。

**第一件：三个"接近 1+1"的端点，其实都是 1+1 的推论。**
Chen 的 1+2 是 `N = p + q`（`q` 为素数，或两个素数之积）；Li–Liu 与 Wu 是
`N = p + r·q`（`r = 1` 或 `r` 为素数）。三种形状都把"两个素数之和"作为特例——
把 `r` 取成 `1`、`q` 取成素数，它们立刻从 `BinaryGoldbach` 推出来——三条定理：

```
binaryGoldbach_implies_chen
binaryGoldbach_implies_onePlusOneNine
binaryGoldbach_implies_onePlusOne8938
```

它们比 1+1 **弱**，不是"差一点点的 1+1"。另有三条机器见证说明端点的表示谓词确实更宽
（Chen 允许第二个加数是 `4 = 2·2`；Li–Liu 允许 `18 = 3 + 3·5`；Wu 允许 `13 = 7 + 2·3`）。

**第二件：一篇新预印本的定理，在它自己的定义下已经蕴含 1+1。**
[arXiv:2611.09007v1](https://arxiv.org/abs/2611.09007)（2026-11-06）第 111 行把
`f = O(g)` 定义为 `lim f(n)/g(n) = c ≠ 0`。按这个定义，它的定理 1.1
（`G(2n)·log²(2n)/n → c`）直接推出 `c > 0`，从而每个充分大偶数都有哥德巴赫表示。
我们把这条推理形式化为

```
paperTheorem_implies_binaryGoldbach
```

也就是说：该文第 180 行把当前情形 `G(2n)` 列入"可以假设"的对象，构成循环；同一句把"`G(2n-2) > 0`"当作输入，在字面定义下已预设结论的正性，在标准读法下则失去依据。
这不是"某个不等式算错了"，是定理陈述本身已经包含结论。

## 必须一起说的话

- **没有证明哥德巴赫猜想。** 本工作没有任何一条无条件定理以 `BinaryGoldbach` 为结论。
- **没有证明"端点推不出 1+1"**：那需要元数学论证；三条见证只说明谓词更宽。
- **不声称"首个"**：检索范围与日期写在 `PRIOR_ART.md`，只说明"没找到"。
